# StockFinderPro

## Setup

```bash
git clone git@github.com:AI-Consultant-2026/StockFinderPro.git
cd StockFinderPro
npm install
cp .env.example .env
```

## Scripts

```bash
npm run dev    # run src/index.ts directly with ts-node
npm run build  # compile TypeScript to dist/
npm start      # run the compiled output from dist/
```
